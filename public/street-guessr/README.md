# Street Guessr

一个类似 GeoGuessr 的本地网页小游戏。

## 使用方法

1. 在 Google Cloud 启用 Maps JavaScript API。
2. 创建一个 API key。
3. 打开 `index.html`。
4. 输入 API key，点击开始游戏。

## 玩法

- 左侧是 Google 街景。
- 右侧地图上点击你猜的位置。
- 提交后按距离计算本回合得分。
- 一局 5 回合，总分越高越好。

## 注意

Google Maps Platform 可能产生费用，请给 API key 设置 HTTP referrer 限制和配额。
